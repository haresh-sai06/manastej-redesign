# Manastej: redesign concept

A premium, motion-rich redesign concept for [manastej.com](https://manastej.com), built with Next.js 15 (App Router), Tailwind CSS v4, GSAP ScrollTrigger and Lenis.

All copy comes from the current manastej.com. See [`DESIGN.md`](./DESIGN.md) for the concept, inspirations, motion system and open TODOs.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build && npm start
```

Screenshots (desktop, mobile and reduced-motion) are in [`screenshots/`](./screenshots).
